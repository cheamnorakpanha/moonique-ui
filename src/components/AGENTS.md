# Storefront UI

Group components by layout, sections, products, cart, checkout and shared UI. Use typed props, compose existing primitives and add loading or error feedback when a flow needs it. Use mobile-first Tailwind utilities and shared CSS tokens. Maintain Modern Artisan and Khmer Heritage styling with Warm Ivory #FAF6EF, Deep Brown #6F3828, Caramel #B77A45, Golden Yellow #D9A441 and Banana Leaf Green #314D36. Maintain readable contrast, touch targets, focus management and reduced-motion behavior. Reuse accessible dialog primitives for overlays.
